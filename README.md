# Task Tracker API (pet-проект, не связан с тестовым заданием)

Не делал отдельное тестовое под фронтенд-кейс — специализация Backend, приложил как образец
кода трекер задач на FastAPI + SQLAlchemy с тестами на pytest.

## Запуск

```
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
```
